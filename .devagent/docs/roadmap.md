# OHM roadmap scaffold

1. **Contract (Pi implemented)** — Pi response envelope, stable identity, and trust boundaries exist; cross-harness metadata remains future work.
2. **Pi adapter (implemented)** — `/ohm` captures latest assistant response and opens private local app handoff.
3. **Claude adapter** — map command and transcript lifecycle to same envelope.
4. **Review suite (Pi latest-response slice implemented)** — Vue shell, sanitized Markdown, local code highlighting, safe links, inert images, themes, and copy action.
5. **Scratchpad (implemented)** — independent note editor with local persistence keyed to response identity and desktop bottom-sticky layout.
6. **Verification (partial)** — Pi adapter, browser behavior, sanitization, offline runtime, narrow layouts, and scratchpad unit coverage exist; Claude and full browser automation remain.

This is a planning index, not an implementation task list. Track executable work in OpenSpec changes.
