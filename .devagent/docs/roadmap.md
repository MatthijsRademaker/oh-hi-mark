# OHM roadmap scaffold

1. **Contract** — define response envelope, identity, metadata, and trust boundaries.
2. **Pi adapter** — capture latest assistant response behind `/ohm`.
3. **Claude adapter** — map command and transcript lifecycle to same envelope.
4. **Review suite** — scaffold Vue shell, Markdown rendering, code highlighting, and safe links.
5. **Scratchpad** — add independent scrolling, persistence, and response-keyed notes.
6. **Verification** — test both adapters, browser behavior, sanitization, and narrow layouts.

This is a planning index, not an implementation task list. Track executable work in OpenSpec changes.
